# ffxiv-submarine-planner
# 🚢 FF14 部队潜水艇懒人管家 & 配装航线规划器 (Lv.1 ~ Lv.145)


一个专为《最终幻想14》（FFXIV）部队工房打造的全自动潜水艇配装与练级/打捞航线规划工具。  
不同于传统的固定配件排表工具，本工具支持**根据当前潜艇等级与已开启海图节点，毫秒级同步遍历「部件组合 × 节点路径」**，直接输出**最优/ 次优/ 再次优**方案，并自带四艘潜艇的实时出航倒计时与一键结算自动升级功能。

## ✨ 核心功能亮点

1. **⚡ 毫秒级「配装 × 路线」双维同步寻优（0秒误差）**
   * 内置客户端底层 `SubmarineExploration` 全部 7 张海图（溺没海、灰海、翠浪海、妖歌海、紫礁海、南苍茫洋、北洋）共 150 个节点的精确三维坐标 $(X,Y,Z)$、探索距离与探索时间参数。
   * 航行距离与地球时间计算精确到秒，与游戏内实际返航时间 **0 秒误差**。

2. **💰 内置 1~145 级《经济平民流》极简配装池**
   * 结合主流攻略并推演至 85-145 级后期海图：从初始 `1111` 起步，**全程仅需额外购置 1~3 个低阶配件（如 `1111` → (15級)`1121` → (25)`3113` → (50)`1123` ）** 即可一图到底升满 145 级，大幅节省部队金币成本。
   * 同时支持切换 **全部不改配件**、**常用经典配装（含 3124 / 4254 等）**、**全改顶配池** 以及 **手动指定唯一配装**。

3. **🎨 直观的五维达标高亮与五档 Bonus 经验色标**
   * **五维单独判定**：自动比对航线途经节点的海图阈值，达标的属性显示为 **亮绿色**，未达标显示为 **暗灰色**（`探 / 收 / 速 / 距 / 恩` 一目了然）。
   * **真实 Bonus 经验期望计算**：根据探索档位、收集档位与恩惠过线情况，自动计算期望总经验与升级所需趟数，并按五档稀有度着色：
     * 🟨 **1档（金）**：全属性三档过线（期望经验 `+75%`）
     * 🟪 **2档（紫）**：收集三档 + 恩惠过线（期望经验 `+42.5% ~ 45%`）
     * 🟥 **3档（红）**：收集二档 + 恩惠过线 或 探索三档 + 恩惠过线（期望经验 `+15% ~ 27.5%`）
     * 🟩 **4档（绿）**：仅探索三档过线 或 单项过线（期望经验 `+5% ~ 18%`）
     * ⬜ **5档（灰）**：基础面板无额外加成（`+0% ~ 2%`）

4. **⚓ 四艘潜艇持久化船坞管家（自动累计经验与连升）**
   * 顶部内置 4 艘潜艇独立档案卡与可视化经验进度条，所有数据自动保存在用户本地浏览器（`localStorage`），刷新或关闭网页永不丢失（不同玩家访问网站的数据互不干扰）。
   * 首次录入等级与经验后，每次点击 **「🚢 选定出航」** 即可开启实时返航倒计时；航程结束后点击 **「✅ 航程结束·累计经验」**，系统自动累加经验、处理满槽连升并自动勾选新等级解锁的海图节点！

5. **🔍 全海图 350+ 种掉落物反向检索**
   * 内置全部 7 张海图的工房材料、常规材料与稀有掉落物（如：`海底黏土`、`黄檀木材`、`纯钛矿`、`炼金树脂`、`狐獴`、`经典眼镜`、`印花阳伞`、`管弦乐谱` 等）数据库。
   * 点击任意搜索结果，自动切换至对应海图、锁定必经打捞点，并切换为「💎 探查达标优先」模式。

## 📖 快速使用指南

1. **首次录入潜艇信息**：点击顶部 `潜水艇-1` ~ `潜水艇-4` 卡片，在下方填入该潜艇当前的 **等级** 与 **当前已有经验**（本级满槽经验会自动查表填入），首次填入的数据会自动备份为初始基准。
2. **勾选已开启节点**：在「3. 本海图已开启节点」中勾选你游戏内已经点亮的目的地；如果有急需摸索开图的前置点（带有黄色边框提示 `→可开启新点`），可点击下方的字母芯片将其锁定为 **必经节点**。
3. **选择收艇习惯**：
   * 喜欢两天收一次艇的省心玩家：保持默认的 **「🛌 少收艇优先」** + **「≤ 48 小时」**。
   * 喜欢掐点极限冲级的玩家：将优化目标改为 **「⚡ 每小时经验最高 (EXP/h)」**。
4. **一键出航与结算**：在右侧挑中满意的方案后，点击 **「🚢 选定此方案并出航」**；等潜艇回港后点击卡片上的 **「✅ 航程结束·累计经验」** 即可自动升级并规划下一趟航程！

## 🛠️ 部件编码速查说明

工具内的 4 位部件编码按游戏内 **【船体 - 船尾 - 船首 - 舰桥】** 的顺序排列：
* `1` = 鲨鱼级 | `2` = 甲鲎级 | `3` = 须鲸级 | `4` = 腔棘鱼级 | `5` = 希尔德拉级 | `改` = 改良型
* *例如：`1123` 代表「鲨鱼级船体 + 鲨鱼级船尾 + 甲鲎级船首 + 须鲸级舰桥」；`4254` 代表「腔棘鱼体 + 甲鲎尾 + 希尔德拉首 + 腔棘鱼桥」。*
