# 🚢 FF14 部队潜水艇管家 & 配装航线规划器 (Lv.1 ~ Lv.145)

一个为《最终幻想14》（FFXIV）部队工房潜水艇打造的配装与航线规划工具，单个网页即可使用，无需安装。

根据潜艇的**当前等级、已解锁的海图节点、手头有哪些部件**，同时遍历「部件组合 × 航线」，给出 **最优 / 次优 / 再次优** 方案。工具有两种规划目标：

- **练级**：按期望经验排名，经验算法与 Dalamud 插件 Argus / SubmarineTracker 一致。
- **捞东西**：按目标掉落物的期望收获排名，掉落数据覆盖全部 7 张海图。

此外还能管理四艘潜艇的出航倒计时、返航提醒和经验结算。

## ✨ 功能一览

### 1. ⚡ 配装 × 航线同步寻优
- 内置全部 7 张海图（溺没海、灰海、翠浪海、妖歌海、紫礁海、南苍茫洋、北洋）共 143 个探索点的三维坐标、探索时间、探索距离和各项门槛。
- 航行时间按游戏公式计算到秒，包括固定的 12 小时。
- 航距公式为 `floor(两点直线距离 × 0.035)`。这和 NGA 攻略记录的游戏内实测值（溺没海 OJ = 59、ROJ = 95、JORZ = 136）完全一致，也和国服 Wiki 部队艇小工具一致。
- 可设置最长地球时间：≤24h、≤36h、≤48h 或不限。
- 可以点字母锁定必经节点。勾选「智能忽略无后续死胡同节点」后，规划时会跳过刚解锁、但没有后续节点的点。

### 2. 📈 准确的经验计算（练级模式）
经验加成采用与 Argus / SubmarineTracker 相同的模型：**每满足一项条件 +25%，最多 4 级（×2.0）**。

| 条件 | 加成 |
|---|---|
| 收集 ≥ 最优门槛 | +1 级，**必定触发（保底）** |
| 探索 ≥ 二档门槛 / ≥ 三档门槛 | 各 +1 级，概率触发 |
| 恩惠 ≥ 门槛 | +1 级，并让探索二档 / 三档各再判定一次 |
| 收集只过普通门槛 | 不加经验 |

- 「经验加成口径」可选 **保底**（默认，与 Argus 相同）或 **平均**。
- 每级升级所需经验、等级成长加成、部件数值均来自游戏数据。
- 排序目标可选：综合均衡推荐（兼顾总经验、效率、开图和常用部件）、少收艇优先、每小时经验最高。
- 85 级以上的潜艇在当前海图暂时无点可开时，会提示可以回溺没海跑 3124 O→J 航线打捞沉船首饰换金币。

### 3. 🎯 掉落物搜索与掉落物优先规划
- **搜物品**：输入物品名或其中几个字（如「钛」），先列出所有名称含这些字的掉落物，以及每个物品有几个掉落点、在哪些海图、属于哪一档。点选后加入目标。
- **多个目标**：最多同时选 5 个物品。它们必须有共同的海图；没有的话会把冲突物品标红，删掉其中任意一个即可。
- **按海图筛选**：列出所有目标共同拥有的海图和每个掉落点的档位、探索要求、档内概率、数量范围。每张海图前可勾选是否参与规划，航线不会跨海图。
- **掉落物优先模式**：完全不看经验，只在掉落点之间排航线，按收益排名。计算方式：
  - 每次探索掉到目标的概率 = 档位触发率 × 档内概率；
  - 恩惠过线时，按该点的二次探索成功率再抽一次；
  - 收集档位（少量 / 中等 / 大量）决定数量。
- **排行榜表头可以点击**：
  - 「收益」：在 **每天期望数量 / 每趟期望数量 / 每趟至少掉 1 个的概率** 之间切换排名依据。
  - 「探索·收集·恩惠」：在 **概览**（如 `可稀有 · 中等 · 可二次探索`）和 **逐点**（每个点一行，与收益逐点对齐）之间切换。
  - 手机上这两个按钮在排行榜列表最上方。

### 4. 🧰 灵活的部件池
| 部件池 | 说明 |
|---|---|
| 💰 经济平民流 | `1111 → 1121 → 3113 → 1123 / 3124` 等少量低阶部件，省部队金币 |
| 🔧 全部不改配件 | 枚举全部未改造部件组合 |
| 📦 常用经典配装 | 常用组合列表，可勾选、删除、输入代码（如 `1111`、`4改2改5改4改`）添加；支持 💾 存为默认、↩️ 恢复默认、🏭 初始化 |
| 👑 全部配件（含全改） | 枚举全部 10,000 种组合 |
| 🧰 当前已有部件组合 | 勾选自己有的部件并填数量，只在库存范围内搭配；其他潜艇正在航行时用的部件会自动扣除 |

所有部件池都会检查部件组装容量上限。

### 5. ⚓ 四艘潜艇船坞管家
- 四艘潜艇各有独立的等级、经验、进度条和所在海图，首次录入的数据会自动备份为初始基准。
- 选好方案后点 **「🚢 选定出航」** 开始返航倒计时。回港后点 **「✅ 结束·累计经验」**，会自动累加经验、处理连续升级，并在打通关底点后自动切换到新海图。
- 返航提醒可多选：响铃、系统通知、网页弹窗 + 手机震动；也可以导出 `.ics` 文件，加到手机或电脑的系统日历当闹钟。
- 海图节点有两层状态：勾选框表示**已解锁**，右侧标签表示**当前等级能否访问**。

## 📖 快速上手

1. **录入潜艇**：点击上方 `潜水艇-1` ~ `潜水艇-4` 卡片，填入当前 **等级** 和 **已有经验**。本级满槽经验会自动填入。
2. **勾选已解锁节点**：在「3. 海图节点状态」里勾选游戏中已经出现在列表上的目的地。
3. **选部件池和目标**：
   - **练级**：保持「综合均衡推荐」，或改成「少收艇优先」「每小时经验最高」。
   - **捞东西**：在「2. 掉落物搜索」里选好物品，排序目标会自动切换为「🎯 掉落物优先」。
4. **出航和结算**：在推荐方案里点「🚢 选定出航」，回港后点卡片上的「✅ 结束·累计经验」。

## 🛠️ 部件编码速查

4 位编码按 **【船体 - 船尾 - 船首 - 舰桥】** 的顺序排列：

`1` 鲨鱼级 ｜ `2` 甲鲎级 ｜ `3` 须鲸级 ｜ `4` 腔棘鱼级 ｜ `5` 希尔德拉级 ｜ `改` 改良型（工具中写作 `4改-2改-5改-4改`）

例：`1123` = 鲨鱼体 + 鲨鱼尾 + 甲鲎首 + 须鲸桥；`4254` = 腔棘鱼体 + 甲鲎尾 + 希尔德拉首 + 腔棘鱼桥。

## ⚠️ 已知局限

- **掉落数据部分是估算**：「档位触发率」和「二次探索成功率」只有 Masika 5.5 掉率表覆盖的 68 个点有实测（溺没海、灰海、翠浪海）。其余的点用平均值估算，结果后面会标 `(估)`。中等探索时的二档触发率也是估算值。
- **数量按档位近似**：各收集档位的数量，是把物品的数量范围平均分成三段近似得到的。
- **南苍茫洋、北洋的航距尚未在游戏内核实**：submarine.girin.dev 在这两张图上的航距比本工具少 1～2，本工具与国服 Wiki 小工具一致。如果你的潜艇已经到了这两张图，欢迎反馈游戏内显示的航距。
